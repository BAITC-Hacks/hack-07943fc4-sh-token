# Входные данные кейса «Граф денег»

Обезличенный датасет организаторов HackAlem AI за июль 2026 года:

- `nodes.parquet` — 2 248 узлов, включая 81 seed-клиента;
- `edges.parquet` — 3 119 агрегированных направленных рёбер;
- `transactions.parquet` — 4 840 отдельных транзакций.

Граф построен только по исходящим переводам на глубину до четырёх колен.
Переводы меньше 5 000 KZT не включены. Узлы на `depth=4` с нулевым
исходящим потоком считаются обрезанными границей наблюдения, а не
автоматически конечными получателями.
